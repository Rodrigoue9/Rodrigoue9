### 👨‍💻 Sobre Mim

Olá! Sou o **Rodrigo Flávio**, Desenvolvedor de Software Full-Stack apaixonado por construir sistemas escaláveis, interfaces web acessíveis e colaborar ativamente no ecossistema de código aberto (*Open Source*).

- 🔭 Contribuidor ativo em grandes ecossistemas globais (**Twenty CRM**, **Documenso**, **Cal.com**, **Payload CMS**, **shadcn/ui**, **LiteLLM**, **Novu**).
- 💡 Foco em engenharia de software de alta resiliência, arquitetura de APIs seguras, acessibilidade (WAI-ARIA APG) e fluxos com IA.
- ⚡ Experiência prática com arquiteturas orientadas a eventos, GraphQL, WebSockets e bancos relacionais.
